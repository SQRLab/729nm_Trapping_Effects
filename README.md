## 729nm_Trapping_Effects
This repository contains files used to simulate the effects of the spatial extent and power of the qubit laser on Rabi Oscillations and single-qubit gate fidelity. 

## trapping_effects
- Defines key constants used in Rabi Oscillation calculation
- Contains the functions used to model the Rabi Frequency and gate fidelity

## plot_effects.ipynb
- Code used to generate plots and analyze effects of waist size
